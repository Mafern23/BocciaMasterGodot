# 🎱 BocciaMasterGodot

Videojuego deportivo y paralímpico inspirado en la Boccia, desarrollado en **Godot Engine**.

## 🎯 Acerca del proyecto
Este proyecto nace con el objetivo de llevar el deporte paralímpico de la Boccia a los videojuegos, enfocándose en las reglas oficiales, mecánicas precisas de lanzamiento, físicas realistas e inclusión.

## 🛠️ Tecnologías y Herramientas
* **Motor:** Godot Engine
* **Lenguaje:** GDScript
* **Control de versiones:** Git & GitHub

## 📁 Estructura del repositorio
* `escenas/` - Escenas principales, niveles e interfaz de usuario.
* `scripts/` - Lógica del juego, físicas y controles en GDScript.
* `Arte/` y `Activos/` - Recursos visuales, sprites y modelos.
* `audios/` - Efectos de sonido y ambientación.
